Verification sources only; do not put these files in your mods folder.

StandaloneSmoke.java is a test-only NeoForge client fixture. It creates a disposable flat world, supplies deterministic native Epic Fight attack/guard input, tests rendering-ownership handoffs, and verifies feature switches. It needs the installed Minecraft/NeoForge development classpath, Combat Punchy, Epic Fight, WOM, Punchy 3.1 and Moves 1.0.3 to compile/run. The source is not needed for normal use.

StartupSmoke.java checks transformed optional-integration classes at the title screen. It was used for Epic Fight alone, Punchy only, Moves only and legacy Punchy 2.8g plus Moves.

tnk-test-moves.zip contains an original minimal idle/crouch clip used for the test. It is not a third-party animation pack or a replacement for a normal Moves resource pack.

See VALIDATION.md and TEST_RESULTS.txt for actual results and limits. Binary test fixtures, game dependencies and generated worlds are not distributed.
